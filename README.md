# 🎓 Курсограф — Платформа онлайн-обучения



**Полнофункциональная платформа для онлайн-обучения с ролевой моделью доступа**


## 📖 Описание проекта

**Курсограф** — это десктопное приложение для управления онлайн-обучением, разработанное на Python с использованием библиотеки Tkinter. Платформа предоставляет полноценную экосистему для трёх типов пользователей: студентов, преподавателей и администраторов.

### Ключевые особенности

-  **Ролевая модель доступа** (Admin, Teacher, Student, Guest)
-  **Создание и управление курсами** с многоуровневой структурой
-  **Разнообразные типы уроков**: видео, текст, интерактивные тесты
-  **Автоматическая проверка тестов** и начисление баллов
-  **Аналитика успеваемости** с графиками и диаграммами
-  **Рейтинговая система** для мотивации студентов
-  **Экспорт отчётов** в CSV и JSON форматах

---

##  Функциональные возможности

### Для всех пользователей
- Просмотр каталога курсов с фильтрацией по уровню
- Поиск курсов по названию
- Детальная информация о каждом курсе

### Для студентов
- Регистрация и авторизация
- Запись на курсы
- Последовательное прохождение уроков
- Выполнение тестов с автоматической проверкой
- Отслеживание прогресса обучения
- Просмотр личного рейтинга и достижений

### Для преподавателей
- Создание и редактирование курсов
- Добавление уроков (видео, текст, тесты)
- Просмотр успеваемости студентов своего курса
- Доступ к аналитике и рейтингам

### Для администраторов
- Полный контроль над всеми курсами и пользователями
- Расширенная аналитика и статистика
- Генерация отчётов
- Управление системой

### Система рейтинга
- **Студенты**: баллы за правильные ответы в тестах + бонус 10 баллов за полное завершение курса
- **Преподаватели**: рейтинг по количеству студентов и успеваемости
- **Курсы**: ранжирование по сложности и популярности
